# Alasan Utama Memilih Next.js untuk Proyek Modern

Next.js menawarkan solusi lengkap (*all-in-one*) untuk pengembangan web berbasis React. Berbeda dengan React SPA konvensional, Next.js mendukung Server-Side Rendering (SSR) dan Static Site Generation (SSG).

Keunggulan utamanya meliputi:
- **SEO yang Optimal:** Halaman dirender di server sehingga mudah diindeks oleh mesin pencari.
- **Routing Berbasis Folder:** Sistem routing otomatis berdasarkan struktur direktori di folder `app/` atau `pages/`.
- **Optimalisasi Aset:** Gambar, font, dan skrip dimuat secara optimal secara *default*.
