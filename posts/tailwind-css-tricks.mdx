# Trik Styling Cepat dengan Tailwind CSS

Tailwind CSS memungkinkan Anda mendesain antarmuka secara langsung di dalam file markup tanpa harus bolak-balik menulis file CSS terpisah.

Beberapa trik praktis yang sering digunakan:
- **Responsive Design Sederhana:** Gunakan awalan seperti `md:` atau `lg:` untuk mengatur tampilan responsif (contoh: `className="text-sm md:text-lg"`).
- **Dark Mode Otomatis:** Manfaatkan modifier `dark:` untuk mengatur warna latar atau teks saat tema gelap aktif.
- **Arbitrary Values:** Jika ukuran atau warna tidak tersedia di tema default, gunakan kurung siku seperti `w-[320px]` atau `bg-[#123456]`.
