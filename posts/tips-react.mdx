# Tips Produktivitas Menggunakan React

Menulis komponen React yang bersih memerlukan pemahaman yang baik tentang struktur kode dan manajemen state. Berikut adalah beberapa tips yang bisa Anda terapkan:

- **Pecah Komponen Kecil:** Jangan biarkan satu file komponen terlalu panjang. Pisahkan bagian UI yang repetitif menjadi komponen mandiri.
- **Gunakan Custom Hook:** Jika Anda mendapati logika `useState` atau `useEffect` yang sama di beberapa tempat, bungkus ke dalam *Custom Hook*.
- **Manfaatkan Destructuring:** Lakukan *destructuring* pada props langsung di parameter fungsi untuk membuat kode lebih mudah dibaca.
