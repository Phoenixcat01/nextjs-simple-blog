# Membuat Kartu Artikel Responsif dengan Mode Gelap Tailwind

Komponen kartu (*card*) adalah elemen yang paling sering digunakan dalam membangun blog atau halaman portofolio. Dengan Tailwind, kita bisa mengatur tampilan interaktif saat kursor diarahkan (*hover*) dan mode gelap dengan sangat mudah.

## Contoh Kode Komponen Kartu

```html
<article class="max-w-sm rounded-2xl overflow-hidden shadow-lg bg-white dark:bg-zinc-900 border border-zinc-200 dark:border-zinc-800 transition-all hover:scale-[1.02]">
  <div class="h-48 bg-gradient-to-r from-blue-500 to-indigo-600 flex items-center justify-center text-white font-bold text-lg">
    Thumbnail Artikel
  </div>
  <div class="p-6">
    <span class="text-xs font-semibold text-blue-600 dark:text-blue-400 uppercase tracking-wider">Tutorial</span>
    <h2 class="mt-2 text-xl font-bold text-zinc-900 dark:text-white">Belajar Tailwind dari Nol</h2>
    <p class="mt-3 text-sm text-zinc-600 dark:text-zinc-400 leading-relaxed">
      Pahami konsep dasar utility-first CSS untuk mempercepat proses pembuatan antarmuka web modern tanpa ribet.
    </p>
    <button class="mt-5 w-full py-2.5 bg-blue-600 hover:bg-blue-700 text-white text-sm font-medium rounded-lg transition-colors shadow-sm">
      Baca Selengkapnya
    </button>
  </div>
</article>

Dengan memanfaatkan modifier kelas seperti dark: dan hover:, antarmuka web Anda akan langsung terasa lebih dinamis, profesional, dan nyaman dipandang mata dalam kondisi apapun.
